# Dataset: Lake Champlain Range Test Detections (Summer 2016)

## Background

This repository makes available the 'Lake Champlain Range Test Detections (Summer 2016)' dataset. This dataset supported the in-field validation analysis in the [`patter-champlain`](https://github.com/edwardlavender/patter-champlain) project. 

The dataset includes acoustic telemetry detections from two transmitters deployed during July and August 2016. 

Data were collected by V. Pinheiro (unpublished). 

The data contact is Matthew H. Futia, mfutia@brockport.edu.
