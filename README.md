# Dataset: Lake Champlain Range Test Detections (Summer 2026)

## Background

This repository makes available the 'Lake Champlain Range Test Detections (Summer 2026)' dataset. This dataset supported the in-field validation analysis in the [`patter-champlain`](https://github.com/edwardlavender/patter-champlain) project. 

Data were collected by Pinheiro (unpublished). 

The data contact is Matthew H. Futia, mfutia@brockport.edu.
